# Netflix Movies and TV Shows – Data Science Project

## Project Overview
This project analyses Netflix Movies and TV Shows using Python, Data Analysis and Machine Learning.

## Dataset
Netflix Movies and TV Shows dataset from Kaggle.

- Total records: 8,807
- Original columns: 12

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Steps
1. Data Inspection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Encoding and Scaling
6. Machine Learning Model Training
7. Model Evaluation
8. Netflix Content Recommendation System
9. Data Visualization
10. Interactive Recommendation Interface

## Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)

## Recommendation System
Used TF-IDF and Cosine Similarity to recommend similar Netflix titles based on genres and descriptions.

## Project Outcome
Created an interactive Netflix recommendation system that suggests five similar titles based on a selected title.
